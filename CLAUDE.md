# Istruzioni per Claude

## Ricerca di repository
Quando l'utente chiede se conosci una repo (o un progetto), cercala subito dove può essere: su tutto GitHub
(repository pubblici) e, se non la trovi, sul web. Non limitarti ai repository collegati all'account o ai connettori:
quelli l'utente li conosce già. Se una ricerca è limitata, dillo esplicitamente indicando dove hai cercato.
